# Repository cleanup report

No repository files were deleted or moved during deployment preparation. The source and runtime paths are interconnected: Python CLI imports use `backend.cli.*`, data files resolve under `backend/data/`, and the Node bundle sets `WORKSPACE_ROOT` to the repository root. Reorganizing those paths would risk breaking the current application and was not necessary to build separate deployments.

## Identified generated or potentially redundant material

- `frontend/assets/index-D_tfUWMO.css` and `frontend/assets/index-BiIN_y8_.js` look like older generated bundles. The active `frontend/index.html` loads `/src/main.tsx`; Vite writes current output under `frontend/dist/`; the local launcher serves `frontend/dist/`. The older assets are retained because no deletion was requested and they may be user-retained deployment artifacts.
- `api-server/dist/` is generated by `npm run build`; the local `npm start` command uses it. Deployment rebuilds it from `api-server/src/`. The files are retained for existing local startup compatibility.
- `docs/screenshots/` contains screenshots referenced by historical implementation reports; retained.
- `extension-dev/` is a separate test copy with explicit development hosts; retained for testing and never used for production extension packaging.
- `ffcs-os-package.zip` is outside this Git repository at the parent workspace level; it was not inspected for cleanup or modified.
